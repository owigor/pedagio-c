# Sistema de Pedágio em C

Projeto desenvolvido para a disciplina de Algoritmos e Pensamento Computacional.

## Sobre o projeto

Este programa simula o controle de carros que passam por um pedágio durante os 7 dias da semana. Ele armazena os dados em um vetor, calcula o total de veículos, a média diária e identifica o dia de maior e menor movimento.

## Funcionalidades

- Leitura dos dados de 7 dias.
- Cálculo do total de carros na semana.
- Cálculo da média diária.
- Identificação do "Dia de Pico" (maior movimento).
- Identificação do dia mais fraco (menor movimento).
- Validação para impedir números negativos.

## Tecnologias utilizadas

- Linguagem C
- Compilador GCC

## Como executar

gcc pedagio.c -o pedagio
./pedagio
